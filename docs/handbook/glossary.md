# 📖 Handbook: Glossary (Glosario & Entidades)

> **Proyecto:** RoomIA  

---

## 🔤 Términos & Siglas

* **RoomIA:** Nombre del producto (Roomie + Inteligencia Artificial).
* **Solo Expat:** Perfil de usuario que se traslada solo a una nueva ciudad o país.
* **Roomies / Convivencia:** Perfil de parejas o compañeros de casa que comparten gastos y tareas.
* **Tavily AI Search:** API de búsqueda optimizada para LLMs y agentes de inteligencia artificial.
* **AWS SAM (Serverless Application Model):** Framework de AWS para definir infraestructura serverless como código (IaC).
* **RAG (Retrieval-Augmented Generation):** Técnica de IA que combina modelos generativos con información indexada de documentos.
* **SOAP (Subjetivo, Objetivo, Análisis, Plan):** Formato estándar de documentación de la salud en la Ficha Médica de Emergencia.

---

## 🧩 Entidades del Dominio

* **CityEvent (Evento de Ciudad):** Objeto que representa una actividad cultural, concierto, feria o meetup en la ciudad.
* **Ingredient (Ingrediente):** Elemento de alacena/refrigerador escaneado o dictado por voz.
* **SharedExpense (Gasto Compartido):** Transacción registrada entre dos o más roomies con tipo de división (50/50 o proporcional).
* **Task (Tarea del Hogar):** Actividad doméstica asignada equitativamente a un usuario.
* **EmergencyCard (Tarjeta de Emergencia):** Ficha médica exportable con tipo de sangre, alergias y contacto de emergencia local.
